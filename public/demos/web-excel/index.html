05 / 其他候选与取舍

候选本轮决策
Handsontable排除：商业使用需要商业许可；不使用非商业评估密钥代替。
Univer专项评估：更适合完整电子表格工作区；能集成 Vue 3，但 UMD 仍带 React 运行时。核心 + 中文 + 排序 + 筛选实测压缩下载约 2.82 MB。查看证据
Luckysheet / x-data-spreadsheet不入围：前者已归档并指向 Univer，后者声明迁移项目。
RevoGrid / Cheetah Grid备选：分别为 Web Components 与 Canvas 路线；本轮优先验证更贴近需求的方案。
TanStack Table有 Vue 适配；headless 需要自行组合 UI 与交互，开发成本较高。
Element Plus Table / V2Vue 3 备选；常规表格与虚拟表格能力不同，复杂交互需额外集成。

06 / 运行与证据

直接双击本页，再进入任一演示。需要联网加载固定版本 JS / CSS；使用 BootCDN、npmmirror 与 jsdmirror 国内社区镜像。可用性为当前环境验证，不代表全部国内运营商。若加载失败，页面会显示具体 URL。

每个演示 HTML 自带样式、数据与逻辑，可单独复制；保留整个目录才能使用返回导航和证据链接。生产部署请遵守各依赖许可，并评估资源自托管。

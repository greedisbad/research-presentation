## 复现方式

```bash
cd assets/screenshots

# 1) 本地项目界面截图（点哪里→等什么→截哪张，配置驱动）
node capture.mjs configs/<项目名>.json

# 2) 代码/文档/JSON 证据裁切（渲染成统一风格的图）
node evidence-shot.mjs configs/<配置>.json

# 3) 大图裁成原分辨率细节图（整图直读会被压缩糊掉小字）
/Users/wang/miniconda3/bin/python3 crop.py <输入> <输出> <left> <top> <right> <bottom> [缩放]
```

**依赖**：截图引擎借用 `cba-demo-3d/node_modules` 里的 Playwright，并用本机 Chrome（`channel:'chrome'`）+ SwiftShader 软件渲染（保证无头模式下 WebGL 正常出图），无需下载浏览器二进制。

**各项目启动方式**：

| 项目 | 入口 |
|---|---|
| cba-demo-3d | `file://…/dist/cba-3d.html`（单文件构建，直开） |
| aircraft-modeling | `vite preview --port 4181`（dist 用绝对路径，需 HTTP） |
| web-excel | `python3 -m http.server 4182 --directory /Users/wang/Documents/ChatGPT/web-excel`（纯静态站，**必须带 `--directory`**） |
| deckgl-rotation | `python3 -m http.server 4183`（纯静态站，CDN 加载 Deck.gl） |
| wps-ai-plugin | `npm run dev`（端口 3889）；工作副本取 `~/Desktop/projects/wps-ai-plugin`（有 node_modules） |
| download-codex / chrome-ai-tab-grouper / worktime-interaction | `file://` 直开（单文件页面） |

每个项目目录下的 `_shots.json` 记录了该批截图的运行时间、文件与说明。

> ⚠️ `_shots.json` **只保留该目录最近一次运行**——同一目录跑第二份配置会覆盖前一份的记录（例如 `web-excel/` 两次运行，只剩后一次）。它只是运行日志，**MANIFEST 才是权威索引**。`evidence-shot.mjs` 与 `crop.py` 不写运行记录。

**`git` 目录需先重建输入**（`/tmp` 会被清空）：

```bash
git -c core.quotepath=false show --stat \
  --format="commit %H%nAuthor: %an%nDate:   %ad%n%n    %s%n" 6cb3e9c > /tmp/gitshow.txt
git log --oneline | head -14 > /tmp/gitlog.txt
node evidence-shot.mjs configs/git-evidence.json
```

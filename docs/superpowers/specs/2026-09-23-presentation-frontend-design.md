# AI 辅助技术调研实践：前端演示工程设计

**日期：**2026-09-23

**状态：**待讲者审阅

**内容来源：**[`42-口播反馈重写版逐页演讲稿.md`](../../42-口播反馈重写版逐页演讲稿.md)；视觉方向沿用已选定的「01 编辑部」样式。

## 目标与边界

把 42 文稿的 24 页叙事制作成可现场播放的前端演示，同时提供四个本地项目的可操作静态 Demo：3D 配载、Web Excel 依赖选择、Deck.gl 台风旋转、Blender 飞机建模结果。演讲页负责讲清观点和展示证据；Demo 仅在需要时从演讲页打开新标签。演讲页不能因为 Demo 加载失败而退出或丢失进度。

交付两个产物：

1. **完整包：**`npm run build:full` 生成含演讲页、独立 JS/CSS/图片与四个 Demo 目录的静态站点。`npm run dev` 从仓库根目录启动相同的演示入口。
2. **单文件包：**`npm run build:single` 生成一个可直接传输和打开的 HTML，内联演讲页需要的 CSS、JS 和精选图片；不包含四个 Demo，也不保留会失效的本地 Demo 链接。

口播、页面任务、内部画面建议和证据边界仅保留在 Markdown，不进入演讲前端的文本、隐藏节点、源码注释、JSON 或单文件包。两种构建都不是把 Markdown 直接渲染为幻灯片。

## 视觉与播放

- 固定 1920×1080、16:9 舞台，按视口等比缩放，不用手机断点重排幻灯片。
- 延续「编辑部」方向：暖纸色背景、深色正文、朱红色强调、细规则线、报刊式标题与编号；用布局变化区分案例，不把 24 页做成同一种卡片模板。
- 低密度、讲者主导。每页只放标题、少量观点或证据标签；原口播不放上屏。若某页内容放不下，拆分或精简屏幕文字，不缩到难读。
- 键盘方向键、空格、触控切换；提供页码和进度。演示链接使用正常 `<a target="_blank" rel="noopener">`，不使用会被弹窗拦截的脚本开窗。
- 首页与每个案例页都可通过目录跳转；从 Demo 返回时演讲页保留原页。减少动态网络依赖和大动画；支持 `prefers-reduced-motion`。

## 内容和图片准入

演示内容以最新 42 文稿的 24 页为唯一叙事顺序，不以旧 `review-state.json` 的 28 页为准。每页建立独立的屏幕文案和配图声明，不自动搬运 `assets/presentation/42/` 中旧页码对应的图片。

图片先做逐项审计，再进入精选清单：记录原始路径或来源 URL、画面实际内容、所属页面、是否为真实截图/公开网页/示意、裁切方式和使用状态。以下规则是硬边界：

- WPS 项目介绍使用 [`2026-05-24-japan-progress.png`](../../../assets/cases/wps/history-2026-05/2026-05-24-japan-progress.png) 这张历史真机图，不把 Web 适配页当成 WPS 真机画面。
- ECharts 公司问题只能用明确标注的示意图；4.9.0/6.0.0 对照可以用独立实验的真实截图，不冒充公司项目。
- 搜索结果页、微软/WPS 文档、中国货运航空页面等外部画面，需先核对页面和截取范围；不把目录页、无法显示正文的截屏或错误搜索结果作为正面证据。
- WPS 候选拼装、项目记忆文件树、B747 检索链、ECharts 反复失败等优先用 HTML/CSS 绘制，不生成假网页截图。
- 本地项目页优先使用从真实运行页面重新截取的画面；若需要临时占位，必须在配图清单里标记，不能作为最终成品暗中保留。

## 四个 Demo 的接入方式

演讲工程不修改四个源项目。构建脚本默认从本仓库的四个兄弟目录 `../cba-demo-3d`、`../web-excel`、`../deckgl-rotation`、`../aircraft-modeling` 读取或构建；允许用演讲项目专属环境变量覆盖目录，避免把用户名路径写死在代码里。构建前检查来源存在，复制后检查入口和关键静态资源。每个 Demo 在演讲页同时有一张独立于其运行状态的静态画面或 HTML 示意。

| Demo | 来源与打包 | 已知风险与兜底 |
|---|---|---|
| 3D 配载 | 对 `cba-demo-3d` 执行既有 Vite build，复制 `dist/`、模型与相对资源 | WebGL、GPU 或模型失败时保留舱位截图与结构示意 |
| Web Excel 选型 | 复制 `web-excel/index.html`、`demos/` 和演示所需的本地资源 | 原页面加载固定版本 CDN；断网时演讲页仍展示索引与代表性操作截图，不把 CDN 成功写成离线保证 |
| Deck.gl 旋转 | 复制四个实验 HTML 及其共用 CSS/JS/图标资源 | Deck.gl 由 CDN 加载且依赖 WebGL；失败时演讲页用经核对的静态对照与短序列说明现象 |
| Blender 飞机 | 对 `aircraft-modeling` 执行既有 Vite build，复制 `dist/`、GLB/纹理/品牌素材 | 模型加载或 GPU 失败时保留真实渲染截图；不把概念模型说成工程数据 |

完整包的来源代码、生成资产与许可证文件要可回查。单文件包不复制 Demo，不下载或内联四个 Demo 的 JS/GLB；其 Demo 按钮变成“单文件版未包含现场演示”的静态提示，页面里的截图继续可用。

## 工程结构与构建

在仓库根目录建立 Vite 前端项目，便于直接运行 `npm run dev`。`src/presentation/` 分别负责：幻灯片数据、视图组件、导航状态、精选资产映射和 Demo 链接。保留研究资料库现有 `docs/`、`review/` 和 `prototypes/`，不把审稿页当最终入口。

`scripts/sync-demos.mjs` 负责从四个源项目准备完整包；`npm run dev` 和 `npm run build:full` 会先执行同步，再启动或构建。同步结果进入忽略版本控制的生成目录，不能因上次留下的旧产物让本次缺失来源悄悄通过。标准 Vite 构建输出多文件站点。单文件构建使用独立配置，将演讲页所需样式、脚本和精选图片内联，并在编译时排除 Demo 链接及生成目录。两个构建共享同一套幻灯片内容和视觉样式，不能各自维护一份文案。

复制第三方库、模型素材和网页截图之前记录来源与许可证；不把不允许再分发的素材混进完整包或单文件包。生成的 `dist/`、依赖目录和同步缓存不提交；精选源图、前端源码与配图清单作为有意维护的项目资产提交。

不要求标准包中的所有第三方库完全离线：Web Excel 与 Deck.gl 现有实验依赖 CDN。完整包必须能在联网的目标浏览器打开并逐个验证；断网或 CDN 失败属于明确降级路径，不能导致演讲页空白。单文件包必须在无本地服务器、无 Demo 目录时仍能播放演讲页。

## 验收

1. `npm run dev` 可从仓库根目录打开演讲首页，24 页内容顺序与 42 文稿一致，所有页面不包含口播文本。
2. `npm run build:full` 生成可由静态 HTTP 服务托管的多文件站点；四个 Demo 在新标签打开，主讲页保持原位置。
3. `npm run build:single` 只生成一个 HTML；移离项目目录并断网打开，演讲页、导航和已内联的精选图片仍可用；不含四个 Demo 页面或失效链接。
4. 任一 Demo 不可访问时，演讲页的静态画面和下一页导航仍工作。
5. 在 1280×720 和至少一个手机尺寸视口检查舞台完整、无溢出或重叠；键盘、触控和减弱动态效果均可用。
6. 配图清单中的真实/示意边界与页面显示一致；不出现已知错误图片或将错页码素材误植到新 24 页。

# B747-400F 舱位类型、几何轮廓与尺寸整理（基于顺丰航空舱位图）

> 目的：把顺丰航空公开的 B747-400F 舱位图，与中国货运航空（CKair）公开的 B747-400F/400ERF 轮廓类型页面、其他 B747-400F 装载资料进行对应，得到“舱位 → 轮廓类型 → 形状 → 尺寸”的可用整理。
>
> **重要说明**：顺丰航空公开图片给出了舱位编号/位置，但没有在图片中直接给出每个位置的详细 contour 几何尺寸。因此，下表中“舱位编号对应关系”来自顺丰航空；“PA1 / PA2 / PMD / H4M / HPL / PEB 等轮廓与尺寸”主要来自中国货运航空的 B747-400F/400ERF 设备说明，并用其他 B747-400F 资料交叉核对。它可以用于建模和装载预判，但不能替代顺丰航空内部的 W&B / Cargo Loading Manual 作为最终承运批准依据。

---

## 1. 核心结论

1. 顺丰图中的 `LR/LL、MR/ML、PR/PL` 等并不是“同一个仓位的左/右版本”，而是飞机主货舱左右两列的**独立 ULD 位置**。
2. 不能仅通过 `L/R` 字母猜货物轮廓，应按该位置对应的 **contour / build-up type** 判断几何形状。
3. 中国货航 B747-400F/400ERF 页面给出的关键位置映射是：
   - `A1 → PA1`
   - `A2 → PMD`；若仅经鼻门装载，可使用 `PA2`
   - `B1、C、D → PMD`
   - `E 至 T（不含 PL，且 Q 为专用小板位）→ H4M`
   - `PL → HPL`
   - `Q → PEB`
4. `H4M/HPL` 的关键特征是：标准 125×96 in 底板，在 **2.44 m 高度开始收口 0.78 m**；H4M 总高约 **3.00 m**，HPL 总高约 **2.87 m**。
5. 对左右并排的高板位，**实际三维实现应按飞机外侧轮廓镜像处理**。也就是说，右列位置与左列位置的外侧削角方向相反。这个“左右镜像”结论符合 B747 双列主舱几何与公开 contour 资料，但 CKair 网页的纯文字只写“收 78 cm”，并没有用文字明确写“仅单侧”；最终几何应以其示例图/承运人手册为准。
6. `PL` 不能简单当成普通 `PR` 的镜像：它使用单独的 `HPL` 类型，最大高度低于普通 H4M，这是主货舱侧门区域的特殊限制之一。

## 3. 各 contour 的几何形状

以下“正视图”可理解为从飞机纵向看 ULD 横截面；“侧视图”可理解为沿飞机横向看 ULD 的纵向截面。

### 3.1 PMD

**形状：完整长方体，无顶部收口。**

- 底面：约 `3.18 × 2.44 m`
- 高：`2.44 m`
- 适用位置：A2、B1、C、D

### 3.2 PA1 — A1 鼻部特殊轮廓

- 底面：`3.18 × 2.44 m`
- 总高：`2.44 m`
- 从 `1.55 m` 开始收口
- 2.44 m 短边两侧各向内收 `1.22 m`

因此横截面可近似理解为：

```text
       /\
      /  \
     /    \
    /      \
   │        │
   │        │
   └────────┘
```

如果把短边中心设为 `y = 0`，底面宽 2.44 m，则可近似用以下折点建模：

```text
(-1.22, 0.00)
(-1.22, 1.55)
( 0.00, 2.44)
(+1.22, 1.55)
(+1.22, 0.00)
```

纵向长度约 3.18 m。

---

### 3.3 PA2 — A2 鼻门装载特殊轮廓

- 底面：`3.18 × 2.44 m`
- 总高：`2.44 m`
- 从 `1.70 m` 开始收口
- 短边两侧各向内收 `0.40 m`
- 顶部剩余宽度约：`2.44 - 0.40×2 = 1.64 m`

近似正视图：

```text
    ┌────────┐
   /          \
  /            \
 │              │
 │              │
 └──────────────┘
```

横截面折点可近似写为：

```text
(-1.22, 0.00)
(-1.22, 1.70)
(-0.82, 2.44)
(+0.82, 2.44)
(+1.22, 1.70)
(+1.22, 0.00)
```

---

### 3.4 H4M — 主货舱普通超高板

CKair 公开文字参数：

- 底面：`3.18 × 2.44 m`
- 总高：`3.00 m`
- `2.44 m` 高度开始收口
- 收口量：`0.78 m`

对于 B747-400F 双列主货舱，建模时应特别注意：

- 左列与右列的**飞机外侧方向相反**
- 因此在三维装载算法里，应把同一高板 contour 做**左右镜像**
- 内侧（靠机身中心线）通常保持更接近垂直，外侧（靠机身蒙皮）受圆弧机身限制而削角

示意（右列/左列互为镜像）：

```text
右列示意                  左列示意

   ┌───────┐             ┌───────┐
  /        │             │        \
 /         │             │         \
│          │             │          │
│          │             │          │
└──────────┘             └──────────┘
```

> **证据等级说明**：CKair 文字明确确认“2.44 m 处收口 78 cm”，但“仅单侧削角”不是该网页文字直接写出的句子，而是结合其 contour 示例图、B747 双列货舱横截面以及左右位置镜像关系得出的几何解释。若要做认证级模型，应以 Boeing / SF 的正式 contour 图折点为准。

如果采用“单侧外削 0.78 m”的工程近似，2.44 m 宽的顶部有效宽度约为：

`2.44 - 0.78 = 1.66 m`

---

### 3.5 HPL — PL 特殊高板

- 底面：`3.18 × 2.44 m`
- 总高：`2.87 m`
- `2.44 m` 高度开始收口
- 收口量：`0.78 m`
- 仅用于 `PL`

几何可理解为 H4M 的特殊高度版本，但**不能把 PL 直接当成 PR 的完全镜像**，因为 PL 本身存在单独的高度/侧门区域限制。

---

### 3.6 PEB — Q 位小板

CKair 页面：

- 位置：Q
- 尺寸限制：约 `2.23 × 1.34 × 1.50 m`
- 形状：矩形小板/小型矩形 ULD envelope

但其他 747F 公开资料中的标准 PEB 通常为：

- Base：`53 × 88 in`
- Height：`84 in`
- 约：`1.35 × 2.24 × 2.13 m`

因此，**PEB 的物理标准尺寸**与**某承运人在某位置允许的 build-up 高度**需要区分。顺丰 QR/QL 的最终高度应以顺丰内部装载手册为准。

## 4. 下货舱：顺丰图中的位置与尺寸代码

顺丰图的下货舱显示：

- 前下货舱：`11P, 12P, 21P, 22P, 23P`
- 后下货舱：图中还画有 `31, 32, 33, 41, 42, 43, 44, 45`
- Bulk
- 图中注明 `SIZE CODES A, M & N`

B747-400 Cargo Handling Manual 可确认：

- **Size Code A**：`88 × 125 in`
- **Size Code M**：`96 × 125 in`
- **Size Code N**：`96 × 61.5 in`
- 下舱标准 pallet build-up 高度通常约 `64 in ≈ 1.63 m`

### 4.1 前下货舱 11P / 12P / 21P / 22P / 23P

这五个位置可以作为全宽 pallet position 使用。

| 舱位 | 可用尺寸代码 | 典型 ULD | 基底尺寸 | 高度 | 形状 |
|---|---|---|---|---|---|
| `11P, 12P, 21P, 22P, 23P` | A | P1 / PAG / LD-7 类 | `88 × 125 in` ≈ `2.24 × 3.18 m` | 约 `64 in` ≈ `1.63 m` | 低位矩形或下舱适配 contour |
| `11P, 12P, 21P, 22P, 23P` | M | P6 / PMC 类 | `96 × 125 in` ≈ `2.44 × 3.18 m` | 约 `64 in` ≈ `1.63 m` | 低位矩形 |
| `11P, 12P, 21P, 22P, 23P` | N | Half pallet | `96 × 61.5 in` ≈ `2.44 × 1.56 m` | 通常约 `64 in` 级别 | 半长低板 |

Cargo Handling Manual 的图中直接把 11P、12P、21P、22P、23P 画为允许的下舱 pallet positions。

---

### 4.2 后下货舱

B747-400 的后下货舱存在**不同 ULD 配置下的不同编号方式**：

- 全尺寸 pallet 配置常见：`31P, 32P, 41P, 42P`
- 半宽/LD3 类配置会细分成 `31L/31R ... 44L/44R` 等
- 顺丰示意图写成 `31, 32, 33, 41, 42, 43, 44, 45`，因此**不能把这些无后缀编号简单等同为八个 PMC 位**

Cargo Handling Manual 对后下舱明确给出：

- Size A：`88 × 125 in`
- Size M：`96 × 125 in`
- Size N：`96 × 61.5 in`
- Size K：`60.4 × 61.5 in`
- Size L：`60.4 × 125 in`

其中 K/L 类与 LD3/AKE 或双联下舱 ULD 的占位关系有关。

因此，对顺丰图的后下舱，应按“**配置模式**”建模，而不是把 31~45 每个编号固定成一个 3.18×2.44 m 长方体。

---

### 4.3 Bulk

Bulk 是散货舱：

- 不是标准 pallet position
- 空间轮廓跟随机身尾部逐渐收缩
- 不能用一个简单长方体代表全部可用空间
- Qantas 747-400F flyer 给出的 Bulkhold 容积约为 `14.7 m³`
- Bulk 门尺寸约 `47 × 45 in`，即约 `1.20 × 1.14 m`

如果要做精确 3D 碰撞检测，需要单独获取 bulk compartment 的 fuselage contour / station section。

## 5. 对“LR/LL 是否像 A1 被切一半”的最终结论

更准确的说法是：

- **不是把 PA1/A1 的几何直接切成两半。**
- A1 使用的是独立的 **PA1 鼻部 contour**，其顶部是对称向中间收尖。
- LR/LL 这类普通左右高板位使用的是 **H4M** 一类主舱高板 contour。
- 对左右并排位置，真正限制来自飞机左右外侧的机身圆弧，因此左、右位置应当是**镜像 envelope**。
- 所以从“视觉效果”上看，普通高板位确实很像“只有外侧削掉、中心线一侧保持直立”的半边轮廓，但它并不是“把 A1 切一半”，而是另一套 contour 定义。
- `PL` 又是例外：它使用 **HPL**，高度只有约 2.87 m，不能直接用普通 H4M。

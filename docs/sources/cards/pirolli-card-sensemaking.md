# 来源卡：Pirolli 与 Card 的 Sensemaking 模型

- 标题：The Sensemaking Process and Leverage Points for Analyst Technology as Identified Through Cognitive Task Analysis
- 作者：Peter Pirolli、Stuart Card（PARC）
- 日期：2005
- 链接：https://www.researchgate.net/profile/Peter-Pirolli/publication/215439203_The_sensemaking_process_and_leverage_points_for_analyst_technology_as_identified_through_cognitive_task_analysis/links/02bfe50f09ca94efc0000000/The-sensemaking-process-and-leverage-points-for-analyst-technology-as-identified-through-cognitive-task-analysis.pdf
- 来源等级：L1 原始研究论文
- 演示推荐度：S

## 回答的问题

分析人员怎样把大量外部资料转化为可报告结论？技术可以在哪些过程节点提供帮助？

## 可用证据

- Sensemaking 包含搜集信息、将信息重新表示到 schema、操纵表示形成 insight，以及产生知识产品或行动。
- 论文用 `Information → Schema → Insight → Product` 概括转换。
- notional model 包含 information foraging 与 sensemaking 两组循环，且两者之间反复交互。
- 无法被当前表示覆盖的 residue 会促使分析者调整表示。
- 作者明确提醒情报分析任务非常多样，不应从局部类型轻率泛化。

## 对演讲的价值

为“AI 技术调研不是搜索后一次总结，而是证据觅食与框架重组的往返过程”提供理论结构；还能解释资料卡、claim ledger 和 gap matrix 为什么是认知工具。

## 不应过度外推

原研究面向情报分析员且为早期认知任务研究；迁移到 AI 技术调研属于本项目的工程类比，不能当作 AI 提效实证。

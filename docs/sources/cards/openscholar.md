# 来源卡：OpenScholar

- 标题：Synthesizing scientific literature with retrieval-augmented language models
- 期刊：Nature
- 日期：2026
- 链接：https://www.nature.com/articles/s41586-025-10072-4
- 来源等级：L1 同行评审原始研究
- 演示推荐度：A

## 回答的问题

为什么专门的研究系统可能比通用模型更适合多来源综合？

## 系统要素

- 专用开放论文语料库；
- 检索器与 reranker；
- 带引用的长答案；
- self-feedback 推理循环；
- 专门评价检索、正确性与引用的 benchmark。

## 对演讲的价值

可以用来说明：提高研究质量不只是换一个更大的模型，而是改善语料、检索、重排、反馈和评价。它与本项目“先建资料库，再让 AI 结构化”的理念一致。

## 局限

科学论文语料较封闭且结构统一，技术 Web、视频、Issue 和源码更异构；论文中的比较结果不应直接推广到日常技术调研。

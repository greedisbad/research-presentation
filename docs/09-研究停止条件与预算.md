# 研究停止条件与预算

AI 把搜索边际成本降得很低，也因此更容易制造“再搜一点也许更好”的无穷循环。专业调研不是搜到互联网尽头，而是在预先定义的风险、证据质量、覆盖率和时间预算下，知道何时足以支持决策。

## 1. 停止不是“没东西可搜了”

Cochrane Handbook 指出，何时停止搜索应被记录和解释；可用依据包括搜索饱和，以及引用追踪是否仍产生大量新增相关记录。如果 citation search 仍持续找到大量新材料，原搜索策略可能不足。其定性证据指南进一步用 bibliographic sufficiency 描述：扩展新的术语或来源不再产生新的相关研究。

迁移到技术调研，停止条件应是“决策充分”，不是“材料最大化”。

## 2. 五类停止条件

### 2.1 问题覆盖

Research Brief 中每个关键问题至少已有答案，且高风险主张没有空白。问题槽位可标为：已证实、存在冲突、只能实验、超出范围。

### 2.2 证据三角

关键技术结论满足以下至少两类，且最终以运行验证为准：

- 官方文档/标准；
- 源码、Issue、PR、Release；
- 目标环境最小实验；
- 独立高质量研究或复盘。

两篇互相转载的博客只算一条证据链。

### 2.3 新增收益趋零

连续一轮新的查询、来源类型和 snowballing 不再增加：

- 新方案；
- 新关键约束；
- 新反例；
- 会改变决策的版本信息。

可以记录 `新增有效来源数 / 新审阅候选数`。这是透明的经验指标，不应伪装成普适阈值。

### 2.4 决策稳定

把最强反对证据加入后，候选排序和实施选择仍未变化；或剩余不确定性只能通过 spike/真实环境实验解决。此时继续网页搜索的价值低于动手验证。

### 2.5 预算和时效

达到预设时间、费用或上下文预算时，允许停止，但必须交付缺口清单，而不能把未知写成肯定。高时效主题还要设置“演示前复查日”。

## 3. 一个可操作的决策规则

每轮研究结束计算四项：

| 信号 | 继续搜索 | 转入实验/写作 |
|---|---|---|
| 高风险问题 | 尚无一手证据 | 已有一手证据或明确只能实验 |
| 来源扩展 | 新来源持续改变判断 | 新来源主要重复已知内容 |
| 方案排序 | 加入反例后明显波动 | 对反例稳定，边界已写清 |
| 下一步价值 | 新查询预期能降低关键风险 | 本地 spike/访谈/运行验证价值更高 |

可把每轮日志写成：

```markdown
## 第 N 轮停止检查
- 新审阅候选：
- 新纳入来源：
- 新增关键事实/约束/反例：
- 被推翻的旧判断：
- 尚未回答的高风险问题：
- 下一小时最有价值的动作：搜索 / 实验 / 询问专家 / 写作
- 继续或停止的理由：
```

## 4. 不同任务需要不同深度

| 决策 | 典型风险 | 合理深度 |
|---|---|---|
| 了解概念、准备讨论 | 低，可逆 | 少量权威种子 + 一轮反例检索 |
| 选择开发库 | 中，存在迁移成本 | 官方文档 + 多个候选 + 源码/Issue/许可证/漏洞 + spike |
| 生产架构决策 | 高、跨团队 | 多类一手证据 + 压力实验 + 威胁/失败分析 + 决策记录 |
| 安全、法律、医疗结论 | 极高 | 专业流程与责任人；AI 仅辅助，不以通用模板替代 |

## 5. “继续监控”与“一次完成”分开

对仍在变化的模型能力、价格、API 和安全公告，不必让一次研究永不结束。可以：

1. 在某个访问日期冻结报告；
2. 标出时效敏感主张；
3. 为官方 release、advisory 或文档更新设置监控；
4. 只有变化会影响决策时才重开研究。

这样，“完成本次决策”和“保持长期更新”成为两个工作流。

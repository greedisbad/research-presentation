## 目标

为 V01 中断裂的视频流程恢复一个最小原始样本，回答：能否从 BV 标识重新取得平台元数据和音频、生成带时间戳转写，并把聚合洞察回链到作者公开文字。

## 获取结果

### 平台元数据

2026-09-05 直接打开视频页返回 HTTP 412，但 B 站公开 API 返回：

- BV：`BV1DVwLz2EGv`
- 标题：《裸辞回国做独立游戏，花了2万8摸索出的AI编程工作流》
- UP 主：`tyk233`
- 发布时间：2026-03-16
- 单 P，API 时长 1367 秒
- player API 公共字幕列表为空

原始 `view` 与 `player/v2` 响应保存在本地忽略目录，SHA-256 写入 [`manifest.json`](video/BV1DVwLz2EGv/manifest.json)。这避免把经过整理的标题和时长误当成原始响应。

### 音频

项目已有的零依赖下载脚本成功取得 DASH 音频：AAC/m4a，19,447,197 bytes，`ffprobe` 时长 1366.076 秒。整段音频不进入公开仓库，只保留本地路径和哈希。

### 转写

公共字幕缺失，火山 ASR 环境变量不存在，因此没有擅自调用付费服务。本轮安装临时 `faster-whisper 1.2.1`，使用 `base` 模型、CPU int8，对以下三段各抽样 90 秒：

- 00:00–01:30：背景与两类工作流；
- 05:00–06:30：验收标准与 Plan + Review；
- 20:00–21:30：工具交互、worktree 与团队边界。

转写脚本为 [`video_sample_transcribe.py`](scripts/video_sample_transcribe.py)，原始 ASR JSON 留在 `tmp/`，公开仓库只保存[抽样审计](video/BV1DVwLz2EGv/transcript-excerpt.md)。

首次启动遇到 SOCKS 代理缺 `socksio`，补齐该最小依赖后成功。这属于环境失败，不是视频或模型错误。

## 演讲价值

这比单纯展示成功流程更有教学性：

```text
网页 412
→ 公开 API 恢复元数据
→ 无字幕
→ DASH 音频
→ 本地 ASR
→ 专名/数字错误
→ 作者文章回链
→ 未覆盖内容降级
```

推荐度：S。可用 60–90 秒展示“降级链”和一处 `2025 → 2005` 错误，直观说明 AI 转写把不可搜索媒介变成候选语料，但不能自动把它变成可靠证据。

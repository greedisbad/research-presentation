# V01：视频从候选到外证回链

## 要支持的演讲主张

视频不是一种无法检索的“内容黑箱”。AI 可以把候选发现、元数据筛选、音频获取、ASR、主题重组和外部核验串起来；但转写和聚合不是最终证据。

## 流程证据

### 1. 查询矩阵扩大召回空间

- 原文件：`tmp/docs-ditto/docs/superpowers/plans/2026-08-07-bilibili-ai-game-research.md`
- 计划按通用任务、国内外 AI 工具、在线平台、游戏引擎、游戏类型和工作流等 7 个维度列出约 65 个查询。
- 计划同时定义了纳入、跳过和结构化采集字段。

### 2. 先用低成本元数据筛选

候选字段包括标题、BV 号、UP 主、时间、简介、标签、播放、评论和外链。简介含项目、Prompt、工具或完整流程时优先进入深读。

这一层回答“值不值得支付下载和转写成本”，不判断技术结论是否正确。

### 3. 字幕不可用时降级到音频 + ASR

- 下载流程：`tmp/docs-ditto/.claude/skills/bilibili-audio-download/SKILL.md`
- 转写流程：`tmp/docs-ditto/.claude/skills/volcengine-audio-transcribe/SKILL.md`
- 脚本：`tmp/docs-ditto/scripts/bili-audio-dl.js`、`scripts/volcengine-asr.js`

本地 Skill 记录了断点续传、限速、失败跳过、大文件压缩、串行重试和输出命名等经验。这说明一次性的手工流程已经被转成可复跑协议。

### 4. 从按视频整理升级为按问题重组

- 总览：`tmp/docs-ditto/docs/research/B站AI游戏开发-总览.md`
- 聚合洞察：`tmp/docs-ditto/docs/research/_insights/工作流-洞察.md`
- 其他视图：按工具、按引擎、资源和独立洞察。

同一个视频可以同时进入多个问题视图；多个视频也可以共同支持“PRD 先行”“分步实现”“人工验收”等候选共识。这就是视频文本从“摘要集合”转成可查询知识库的关键步骤。

## 单视频样本：BV1DVwLz2EGv

### 候选发现

- 标题：《裸辞回国做独立游戏，花了2万8摸索出的AI编程工作流》
- BV 号：`BV1DVwLz2EGv`
- 本地分类条目记录作者、时长、简介中的 PRD 文章链接和推荐理由。

### 聚合提取

本地洞察从视频转写中整理出：发散需求、PRD、Plan + Review、实现、测试迭代、人工 Review，以及把固定流程 Skill 化。

### 外部回链

作者公开了同主题文字文章：

- https://tyksworks.com/posts/ai-coding-workflow-zh/

因此演讲中的流程结构优先引用作者文章；视频用于说明“如何从非文本媒介发现高价值来源”。成本、自报效率和逐字口播仍保持为作者个人经验。

## 2026-09-05 单样本补证

[`V02`](V02-BV1DVwLz2EGv单视频原始链.md) 已重新取得 `BV1DVwLz2EGv` 的平台元数据和 1366 秒音频，并用本地 faster-whisper 对开头、中段、尾段共 270 秒生成带段级时间戳的抽样转写。两个样本与作者文章的工作流结构强对应；尾段文章覆盖不足。ASR 同时出现 `2025 → 2005`、Claude Code 和“验收标准”等明显识别错误。

因此，本案例已证明单视频的“元数据—音频—抽样 ASR—文章回链”可以重新执行，但没有恢复旧批处理的原始 123 份转写，也没有完成人耳回听。

## 当前证据上限：本切片尚未完全闭环

压缩包中没有 `transcripts/`、音频、下载日志、API 原始响应或逐字时间戳文件。当前只能确认：

- 计划、Skill、脚本和聚合产物存在；
- 聚合产物声称处理了 123 个文件；
- 多处主动标记了纯音乐、无有效口播、BV 未匹配和 ASR 误差；
- 单视频流程可回链作者文章。

当前不能独立复核：

- `123/123`、费用和准确率数字；
- 某句视频原话及时间戳；
- 当时 B 站 API 返回的原始元数据；
- 从音频到某段聚合文字的逐步变换。

因此完整度标为“部分完整”。正式演讲有两种安全方案：

1. 当前可展示 V02 的单视频恢复链和 ASR 错误，但逐字引用前仍需人工回听；
2. 对旧批处理仍只展示流程架构和聚合前后的结构变化，不声称 123 份转写已被独立复核。

## 可迁移方法

- 先用元数据评分控制昂贵步骤；
- 为字幕失败准备降级路径；
- 输出按研究问题重组，不按媒介顺序堆摘要；
- ASR 中的产品名、命令、数字和链接必须二次核验；
- 视频最适合发现实践线索，关键事实最终回到作者原文、官方文档、源码或实验。

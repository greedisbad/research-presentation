## 最适合上台的两种用法

1. **宿主证据**：使用中国主题完成图，先裁切保留 WPS 左侧缩略图、中央正文和右侧任务窗格。讲述“当时的插件确实在 WPS 客户端内生成多页演示”，避免把右侧绿色完成提示扩大解释为质量验收。
2. **闭环反例**：使用苏格拉底进度图，圈出可见的重叠/布局问题。讲述“即使工具动作逐项完成，也要回到实际画面查看”；不必指称具体错误原因，因为截图本身无法证明是 prompt、adapter 还是 WPS API 导致。

- 不能证明 2026-09 当前下载快照、当前 WPS 版本与当前模型端点仍能成功运行；[`W04`](W04-WPS模板迁移到运行门禁.md) 的**当次真机门禁仍未执行**。

- 不能从文件名重建运行命令、插件 commit、模型版本、耗时和完整成功率。
- 截图中的“生成完成”是插件 UI 状态；文稿应写“截图显示当时在 WPS 中产生多页内容”，而非“已通过全面验收”。

# 外部研究冻结清单

## 冻结决定

自 2026-09-08 起，长版演示第一稿不再主动扩展新的外部研究主题。现有材料已经覆盖演讲所需的主要问题族：检索与查询扩展、信息觅食与意义建构、程序理解、源码/Issue/Release、开源筛选与许可证、视频转写、引用审计、Agent 安全、验证与知识沉淀。

“冻结”不是宣称互联网已搜索完，也不是禁止修正错误。它表示新的时间优先投入故事板、证据画面和讲稿；只有出现能改变核心结论的缺口，才重新打开定向研究。

## 不再主动扩展的主题

- 新的 AI 搜索产品清单、功能排行或品牌比较；
- 更多“某公司使用 Agent”的相似厂商案例；
- 更多没有原始数据的效率百分比；
- 更多 B 站视频数量和观点聚合；
- 与当前四条主线重复的论文、博客和大师语录；
- 案例内部的 API 教程、游戏机制和视觉实现细节；
- 不能改变演讲决策的 Stars、播放量和热度数据。

这些内容以后仍可进入资料库，但不阻塞 9 月 9 日的长版故事板。

## 保留但不靠搜索解决的缺口

| 缺口 | 为什么继续网页搜索价值低 | 下一动作 |
|---|---|---|
| WPS 真机生成与可编辑性 | 只能由目标宿主裁决 | 按真机采集协议执行 |
| 视频逐字引语准确性 | 已有音频，问题在人工回听 | 需要引用时定点回听 |
| Deck.gl 跨浏览器/GPU 表现 | 当前单环境已满足方法演示 | 若主体声称兼容性，再扩展运行矩阵 |
| 旧 123 份转写是否完整 | 原始对象缺失，搜索不能恢复本地历史 | 保持“聚合记录”限定 |
| 本方法是否普遍提效 | 需要对照任务，不是更多观点来源 | 演讲后另设小型评测 |
| 冷读者能否沿索引复核 | 需要真实读者测试 | 长版完成后执行冷读 |

## 允许解冻的触发条件

只有满足以下任一条件才新增外部研究：

1. 故事板出现一个没有一手证据、且不能改写为本地经验的核心判断；
2. 两个高质量来源发生会改变结论的冲突；
3. 官方版本、链接、许可证或产品能力发生变化并影响演示；
4. WPS 真机或现场彩排暴露新的高风险技术未知；
5. 冷读者无法理解某个关键概念，且现有材料无法补足。

解冻时只建立一个目标明确的查询任务，记录“要改变哪个判断”和停止条件；不重新启动开放式漫游。

## 演示冻结前仍需复查的易变字段

- Deck.gl 9.1.12 tag 与使用的 CDN 资源；
- Chrome/WPS 官方入口是否仍可达；
- WPS 真机版本、插件 URL 和生成报告；
- 被实际引用的外部仓库许可证；
- 视频与作者文章是否仍可访问；
- 最终演示稿中的每个外部链接和页脚日期。

这些属于事实维护，不属于新增研究主题。

## 停止记录

- 新增主题的边际收益：近期材料主要强化既有观点，没有形成新的主线角色；
- 当前高风险空白：集中在真机、人工回听和冷读，均不能由继续广搜消除；
- 决策稳定性：WPS、视频、Deck.gl、Tabloom/Dice 的角色和 S/A/B 优先级在反证与易变事实复核后未改变；
- 下一阶段最有价值动作：把现有 S/A 证据组织成完整故事板。

因此，本轮外部研究达到“决策充分”而非“材料穷尽”，正式转入长版叙事编排。

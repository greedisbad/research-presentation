# 证据综合与引用审计：有链接不等于有依据

## 核心判断

AI 报告最危险的状态不一定是“没有引用”，而是引用齐全、语气确定，但链接只支持附近的一小部分文字。引用审计必须把报告拆到主张级，分别检查：

```text
链接是否真实存在？
→ 来源是否值得用于这个问题？
→ 引文是否支持紧邻主张？
→ 主张中的每个限定词是否都被支持？
→ 重要主张是否都有引用？
→ 多来源冲突和版本边界是否被保留？
```

## 一、先区分五个常被混为一谈的概念

| 维度 | 要问的问题 | 常见假阳性 |
|---|---|---|
| 引用存在性 | 链接、论文、文件和位置是否存在？ | URL 可打开，但指向首页或错误版本 |
| 引用正确性 | 来源是否真正支持紧邻主张？ | 文章谈到同一主题，但没有支持该数字或因果关系 |
| 引用完整性 | 需要外证的重要主张是否都被覆盖？ | 一段末尾只有一个链接，却包含五个独立事实 |
| 来源质量 | 该来源是否适合承担这个结论？ | 用营销页证明性能，用 README 证明安全性 |
| 适用性 | 时间、版本、样本、环境是否匹配？ | 正确的旧版 API 被写成当前版本事实 |

“事实正确”与“引用正确”也不是同一问题：一句话可能碰巧正确，但引用并不支持；反过来，引用可能被准确转述，但原研究不适用于当前工程环境。

## 二、外部研究为什么把引用单独评价

### ALCE：Citation Quality 不是报告流畅度的附属项

Gao 等在 EMNLP 2023 提出 ALCE，用统一任务评价带引用的长文本生成，并把指标分成流畅度、答案正确性和引用质量。引用质量进一步需要考虑支持是否充分与引用是否相关。其 ELI5 设置中，即使当时最佳模型也有大量陈述缺少完整引用支持。[ACL Anthology 原论文](https://aclanthology.org/2023.emnlp-main.398/)

这里最值得迁移的不是某个旧模型分数，而是评价分离：一份文章可以很好读、答案大致正确，同时引用仍然不完整。

### AIS：外部世界主张应能归因到已识别来源

Rashkin 等提出 Attributable to Identified Sources（AIS）：涉及外部世界的生成内容，应能够由一个独立、明确提供的来源加以验证；论文给出两阶段人工标注流程并在多类生成任务上验证。[Computational Linguistics 论文](https://aclanthology.org/2023.cl-4.2/)

对本项目的转译是：不能让审计员只看“句子 + 模型自信度”，必须把原始来源交给审计员，让其判断归因关系。

### Deep Research 评价：报告质量与检索/引用能力仍需分开

DeepResearch Bench 使用 100 个专家设计任务，并分别评价报告质量与有效引用、引用准确性。[2025 预印本](https://arxiv.org/abs/2506.11763)

DeepTRACE 则把报告拆到 statement level，构建 citation 与 factual-support 矩阵，并报告不同公开系统仍会出现缺少来源支持和争议议题单边化。[2025 预印本](https://arxiv.org/abs/2509.04499)

这两项工作仍是预印本且评价包含 LLM judge，适合说明“业内正在怎样审计”，不适合作为某个产品绝对准确率的最终结论。

### DeepFact：连审计基准本身也应该允许被证据纠正

DeepFact 提出 Audit-then-Score：当 verifier 与现有标签冲突时提交证据，由 auditor 裁决，并让接受的修订进入版本化 benchmark。[2026 预印本](https://arxiv.org/abs/2603.05912)

它对日常技术调研有一个很强的启发：claim ledger 不是永久真理表，而是可修订的版本化判断；“人最终负责”也不意味着人第一次判断必然正确，人更适合在证据明确时做裁决。

## 三、引用审计的最小单位是原子主张

原句：

> 工具 A 是目前最快、最安全、完全兼容 WPS 的方案，超过一万 Stars，而且维护活跃。

至少应拆成：

1. 工具 A 在某个明确任务和硬件上更快；
2. 它满足某个安全标准或没有已知风险；
3. 它兼容某个 WPS 版本和目标功能；
4. 某日 GitHub Stars 超过一万；
5. 某个时间窗内存在 Release、commit 或维护响应。

这五个主张的最佳来源不同，也可能只有其中两个已证实。一个链接放在整句末尾无法自动支持全部限定词。

## 四、七步引用审计协议

### 1. 抽取需要外证的原子主张

优先抽取：数字、日期、比较级、最高级、因果、兼容性、安全性、性能、版本、法律/政策和“已经验证”等词。

价值判断可以不伪装成事实，例如“这个案例更适合开场”应标为演讲设计判断。

### 2. 做存在性检查

- URL 能否打开；
- 标题、作者、发布日期是否一致；
- 文件、tag、commit 或版本是否真实存在；
- 是否链接到原文位置而不是搜索结果或二手转载。

### 3. 做 entailment 检查

逐个问：如果只读这份来源，一个谨慎读者能否推出这条主张？

结果只允许四档：

- `FULL`：来源支持完整主张和限定词；
- `PARTIAL`：只支持部分，需要拆句或降低强度；
- `CONFLICT`：来源给出相反或不一致信息；
- `NONE`：主题相关但不能支持主张。

### 4. 做完整性检查

从报告反向扫描，不是从参考文献向前扫描。检查每个重要主张是否至少有一个合适来源；关键决策最好有两种不同证据载体，例如官方契约 + 运行实验。

### 5. 做来源与适用性检查

- 官方文档证明公开契约；
- 源码证明目标版本实现；
- Issue/PR 证明历史讨论与修复过程；
- Release 证明用户可获得版本；
- 实验只证明当前条件下的观察；
- 视频/博客证明作者做法，不证明行业普遍规律。

### 6. 保留冲突，不让 AI 自动平均

冲突来源应并列记录定义、版本、样本、发布日期和利益关系。若无法裁决，输出“当前未解决”，而不是选择语言更流畅的一方。

### 7. 修订主张，而不只是增加链接

常见修订动作：

- 删除无证据限定词；
- 把“证明”改为“在当前实验中观察到”；
- 把“完全兼容”改为“已验证功能 X，Y 尚未验证”；
- 将复合句拆成事实、推断和建议；
- 为时效信息补核验日期；
- 无法核验的引语改为转述或删除。

## 五、适合轻量 Agent 的审计分工

即使没有专门 CitationAgent，也可以用两个互相隔离的回合：

### 生成回合

负责搜索、提取和写作，同时为每个主张附来源位置。不得把“写得完整”当作验收标准。

### 审计回合

只接收主张清单和原始来源，不沿用生成者的解释。逐项输出：

```yaml
claim_id: C-001
verdict: PARTIAL
supported_part: "支持目标版本存在该属性"
unsupported_part: "未证明在 WPS 中兼容"
source_location: "URL / file / tag / line"
recommended_revision: "将完全兼容改为目标版本源码包含该属性，WPS 尚待实测"
```

重要结论最后由人抽样回读原文。审计 Agent 的判定本身仍可能出错，不能形成“模型审核模型所以无需人看”的闭环幻觉。

## 六、一个可直接用于本项目的矩阵

| Claim ID | 原子主张 | 来源 | 位置 | FULL/PARTIAL/CONFLICT/NONE | 来源级别 | 版本匹配 | 修订动作 |
|---|---|---|---|---|---|---|---|
| 示例 | Deck.gl `getAngle` 使用 degree | 官方文档 + 9.1.12 shader | URL + 源码位置 | FULL | L1 | 是 | 保留 |
| 示例 | 四条路线均在浏览器通过 | 本地复盘 | IMPLEMENTATION-NOTES | PARTIAL | 本地记录 | 是 | 标历史记录；补当前运行快照 |
| 示例 | 123 个视频全部准确转写 | 本地 Skill 自报 | SKILL.md | PARTIAL | 本地记录 | 不适用 | 删除“准确”；找回原始样本抽检 |

## 七、与演讲主线的关系

引用审计不应抢占“如何搜索、筛选与整理”的主线，但适合作为流水线的质量门：

```text
搜索与筛选负责扩大候选空间
结构化整理负责形成可比较的主张
引用审计负责阻止证据与结论错位
实验负责裁决文档无法回答的工程问题
```

推荐度：A。正文用一页说明“有链接 ≠ 有支持”，再用 Deck.gl 与视频证据切片各给一个 FULL/PARTIAL 例子。详细矩阵留在附录或仓库。

## 八、证据边界

- ALCE、AIS 的任务与当前商业 Deep Research 产品不同，不能用旧实验数字估算当前系统表现。
- DeepResearch Bench、DeepTRACE 和 DeepFact 为预印本，且部分评价依赖 LLM judge，应明确其研究状态。
- entailment 只检查“来源是否支持表述”，不能自动判断来源本身是否真实、完整或适用。
- 双模型或双回合审计可以降低同源偏差，但不是独立事实保证。
- 高后果结论仍需要领域人员阅读原始材料并承担决策责任。

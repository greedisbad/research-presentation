# AI 辅助技术调研实践

本项目用于准备《AI 辅助技术调研实践》技术分享。

## 一句话主张

AI 的价值不只是替人搜索，而是把“定义问题、发现参考、筛选证据、验证结论、转化为工程资产”串成一条可复用的技术情报流水线。

## 推荐的最终演讲结构（暂定）

1. 为什么“会问 AI”仍然不等于“会做技术调研”
2. 技术情报流水线：七个阶段与人机分工
3. 案例一：从陌生 WPS API 到可运行插件
4. 案例二：从几十个视频到可检索知识库
5. 案例三：从 Deck.gl 生成失败到文档—源码—实验链
6. 短案例：用 Dice 复盘保存负知识和任务交接
7. Tabloom 元案例：让错误、用户反馈与真实边界生成下一轮信息缺口
8. 验证闭环：关键事实、关键未知和匹配媒介
9. 如何把一次调研沉淀为下一次可复用的能力
